# Security Policy / 安全策略

## Supported Versions / 支持版本

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability / 漏洞报告流程

LanChat takes application and local network security seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report it via private email:
- **Email**: `zsy2542068503@163.com`
- **Subject**: `[SECURITY VULNERABILITY] LanChat - <Short Description>`

Please include:
1. Detailed description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept (PoC) code.
3. Affected versions, platforms, and network conditions.
4. Suggested remediation if available.

We will acknowledge receipt within 48 hours and work with you to analyze, fix, and coordinate disclosure.
